Clinical Background & Problem Formulation

The Problem: Adherence Breakdown & Prescription Illegibility

Current healthcare management suffers from fragmented communication circles and complex handwritten medical instructions.

⚠️ Critical Clinical Challenges

  • >125,000 Annual Preventable Deaths: Caused by missed doses, incorrect timings, or unintentional polypharmacy overdoses.
  • Fragmented Care Circle: Guardians and nurses have zero live visibility into whether an elderly or outpatient actually took their dose.
  • Illegible Latin Prescriptions: Doctor scripts use cryptic shorthand (PO, qd, bid, tid, hs, prn), causing transcription errors.
  • Legacy App Failures: Generic phone alarms lack verification, multi-user role synchronization, and vital sign correlations.

💡 The DoseTrack Solution

  • Connected Care Triangle: A unified, synchronized workspace for Patient (daily timeline), Guardian (remote oversight), and Nurse (clinical rounds).
  • AI Prescription Vision Pipeline: Converts mobile camera photos of doctor handwritten orders into structured medication schedules.
  • Instant SOS & Care Alert Dispatch: Real-time family nudges, missed dose escalations, and 1-tap emergency broadcasts.
  • Clinical Vitals Logger: Correlates Blood Pressure, Glucose, and SpO2 with medication adherence history.

Emphasis 1: Project Methodology · Algorithms & Logic

Core Algorithms & Mathematical Formulations

Algorithmic rigor in patient identity resolution, Latin abbreviation translation, and adherence scoring.

Algorithm 1: Patient Code Collision Resolver

Guarantees unique, human-readable patient binding keys without leaking database autoincrement IDs:

async function generatePatientCode() { for (let i = 0; i < 10; i++) { const code = 'DT-PT-' + Math.floor(1000 + Math.random() * 9000); const [rows] = await db.execute( 'SELECT id FROM users WHERE patient_code = ?', [code] ); if (!rows.length) return code; // Collision-free } return 'DT-PT-' + Date.now().toString().slice(-4); }

Algorithm 2: Latin Abbreviation & Confidence Logic

Maps pharmacological Latin shorthand into structured temporal slots with confidence thresholds:

Latin TermMeaningTemporal Mapping
POPer Os (Oral)Route: Oral Administration
qd / odOnce Daily08:00 AM
bidTwice Daily08:00 AM, 08:00 PM
tidThree Times Daily08:00 AM, 02:00 PM, 08:00 PM
hsHora Somni21:00 PM (Bedtime)

Verification Rule: $\text{Confidence} \ge 0.75 \rightarrow \text{Green Auto-Accept}$, $\text{Confidence} < 0.75 \rightarrow \text{Amber Review Required}$.

Algorithm 3: Real-Time Adherence Scoring Model

Adherence rate $A(t)$ evaluated over a rolling window $W = [t - 7\text{ days}, t]$:

$$A = \left( \frac{\sum_{i=1}^{N} \mathbb{I}(\text{status}_i = \text{'taken'})}{N_{\text{scheduled}}} \right) \times 100\%$$

Where $\mathbb{I}$ is the indicator function, status is updated upon patient click or nurse round confirmation, and missed doses trigger automatic care alert escalations.

PHASE 03
Verification
User inspects autofilled cards. High confidence confirmed in 1 tap; low confidence edited.
➔
PHASE 04
Live Execution
Scheduled doses appear on patient dashboard. Cron checks timestamps every minute.
➔
PHASE 05
Alert & Sync
Dose confirmation, missed alerts, and nurse vitals broadcast across the Care Circle.

🔒 Security & HIPAA Privacy Safeguards

Images are never persisted to disk or cloud buckets; they exist purely as in-memory Base64 buffers during inference and are garbage collected immediately. All passwords salted with bcrypt (10 rounds).

⚡ Resilient Graceful Degradation

If external cloud vision APIs experience latency or rate limits, the system seamlessly falls back to the intelligent offline clinical heuristic engine without crashing or blocking the user.

M4: Clinical Vitals & Observation Logger

Files: src/routes/careNotes.js, database/schema.sql

M5: Emergency SOS & Nudge Dispatcher

Files: src/routes/alerts.js, src/routes/careTeam.js
• 1-tap SOS Emergency button immediately broadcasts alerts to all linked family guardians and caretakers.
• Guardians can dispatch gentle hydration and meal nudges with custom or preset messages.
